# プラン生成用のベースプロンプト

`data/*.json` をAIに作ってもらうときの土台。【 】の部分を書き換えて、そのまま貼り付けて使う。

---

あなたは旅行プランナーです。下の条件で旅行プランを作り、**JSONだけ**を出力してください。
説明文やコードブロック外の文章は不要です。保存してそのまま使えるJSONにしてください。

## 旅行の条件

- 行き先：【オアフ島（ワイキキ中心）】
- 日程：【2026年11月20日(金)〜23日(月)／3泊4日】
- 同行者：【大人2人】
- 移動手段：【車なし。徒歩・ザ・バス・ワイキキトロリー】
- 宿泊：【ワイキキのホテル】
- やりたいこと：【ビーチでのんびり／ローカルな朝食／夕景スポット】
- 避けたいこと：【早起きが続く行程、1日に詰め込みすぎ】

## 出力するJSONの形

```json
{
  "title": "オアフ島 4日間",
  "subtitle": "2026年11月20日〜23日",
  "days": [
    {
      "label": "1日目",
      "date": "11/20 (金)",
      "theme": "到着してワイキキへ",
      "spots": [
        {
          "time": "13:00",
          "name": "ワイキキビーチ",
          "address": "Waikiki Beach, Honolulu, HI 96815",
          "lat": 21.2766,
          "lng": -157.8278,
          "photo": { "search": "Waikiki Beach" },
          "description": "チェックイン前に荷物を預けて、まずは砂浜へ。遠くにダイヤモンドヘッドが見える定番の景色。",
          "tags": ["ビーチ", "徒歩"]
        }
      ]
    }
  ]
}
```

| 項目 | 必須 | 内容 |
|---|---|---|
| `name` | ○ | スポット名（日本語） |
| `time` | ○ | `"HH:MM"` の24時間表記。現地時間で昇順に並べる |
| `address` | ○ | **現地表記の住所**（英語）。タップでGoogleマップ検索に使われる |
| `lat` / `lng` | ○ | 緯度・経度。小数第4位まで |
| `photo` | | 下の「写真の指定」を参照 |
| `description` | ○ | 日本語で1〜2文（60〜120字）。その場で何をするか、どう嬉しいかを具体的に |
| `tags` | | 短い日本語タグを2〜3個（例：`["ビーチ", "徒歩"]`） |
| `url` | | 公式サイトが確実に存在する場合だけ |
| `zoom` | | 地図の拡大率。既定14。広い公園や海岸線は12〜13 |

## 守ってほしいこと

### 行程

- 1日あたりのスポットは **4〜6件**。移動と休憩の余白を残す。
- `date` は「11/20 (金)」の形式。`theme` はその日を一言で表す短いフレーズ。
- **移動手段と所要時間を `description` に書く**（例：「ワイキキからザ・バス20番で約25分」）。徒歩なら所要分数。
- 初日は到着後の時間から、最終日は出発に間に合う時刻で終える。
- 食事（朝・昼・夕）を少なくとも1日1回はスポットとして入れる。
- 営業日・営業時間が実在の店と矛盾しないようにする。曜日定休がある場合はその曜日を避ける。

### 緯度・経度

- **推測で書かない。** 確信が持てない場合は `lat` / `lng` を省略する（アプリが住所から自動取得する）。
  間違った座標を書かれると地図のピンが見当違いの場所に飛ぶので、省略のほうが安全。

### 写真の指定

写真は Wikimedia Commons から **CC0 / パブリックドメイン / CC BY / CC BY-SA** のものだけを自動取得する。
それ以外（ストックフォト、Instagram、Googleマップ、店の公式サイトの写真など）は使えないので、URLを直接書かないこと。

- 原則として `{ "search": "英語の固有名詞" }` を書く。
  - 良い例：`"Diamond Head"`, `"Hanauma Bay"`, `"Ala Moana Beach Park"`, `"Royal Hawaiian Hotel Waikiki"`
  - 悪い例：`"beach"`, `"shopping mall"`, `"breakfast"`（一般名詞だけだと無関係な写真が当たる）
  - **地名を必ず含める**。`"Chinatown"` ではなく `"Chinatown Honolulu"`。
- Commonsのファイル名を確実に知っている場合のみ `{ "commons": "File:〇〇.jpg" }` で固定する。
  うろ覚えのファイル名は書かない（存在しないと写真なしになる）。
- **個人経営の飲食店・ショップ・ホテル内のレストランなど、Commonsに写真がまず無い場所は `photo` を省略する。**
  無理に `search` を書くより、スポット名入りの色面が出るほうが見栄えが良い。
  どうしても画像を出したいなら、その店が入る建物や通りなど、撮られている可能性が高い被写体名にする
  （例：デュークス・ワイキキ → `"Outrigger Waikiki Beach Resort"`）。

### 書かないこと

- 予約番号、搭乗者名、便名の確認番号、電話番号、メールアドレス、ホテルの部屋番号などの個人情報。
  このページは公開URLで誰でも見られる前提。
- 実在しないスポット、閉業した店。不確かなら入れない。

## 出力

JSONのみを1つのコードブロックで出力してください。コメント（`//`）は使わないこと。
